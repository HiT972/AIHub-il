# AI Hub (AIHub-il)

Сайт на Astro: три псевдонима, три ниши.

- author-1: ИИ-агенты для разработчиков
- author-2: ИИ в бизнесе и финансах
- author-3: ИИ и безопасность

## Как добавить статью

1. Создайте файл `content/articles/<author-id>/<slug>.md`.
2. Заполните метаданные (пример: `content/articles/author-1/first-example.md`).
3. Сделайте коммит в `main`. GitHub Actions соберёт и опубликует сайт.

## Локальный запуск

    npm install
    npm run dev

После публикации сайт доступен по адресу https://hit972.github.io/AIHub-il/
